# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
# 并户继承 → 并户继承夹具 / 并户并发夹具 → 凭证与继承只读视图
# 重叠日窗 → 并户重叠窗票夹具 / 窗票并发夹具 → 重叠窗票核证（票号/重叠日/源正式有无/回放加倍/valid）
```

本地拆跑：

```bash

cd backend && pip install -r requirements.txt
$env:夹具目录='..\fixtures'; uvicorn app.main:app --port 11600

# 前端
cd frontend && npm install && npm run dev
```

## 并户继承镜（已启用）

口径：**源键只读归档**。

- 并户写路径在同一事务内：源户有效快照转「归档」只读 → 流水改挂目标（留 `原账户键`）→ 账户状态
  与去向/凭证 → 清理失效差额 → 落并户凭证 → 重算目标生效日及以后快照。任一步失败整笔回滚。
- 目标户接续源户已公布镜链条：生效日开端 = 目标前日 + 源户结转，且只加一次（目标已有后续有效镜即不再加）。
- 源户生效日后禁抽；并户后按源键装载的流水改挂承接目标。
- `GET /api/快照?账户键=户甲` → 空；`&含归档=true` → 归档只读行。
- 并户继承只读接口：`GET /api/并户/{凭证}` → 源、目标、生效日、`源键暴露`、`valid`、目标继承链、源归档链。
- 夹具：`并户继承样例.json`（顺序）、`并户并发样例.json`（并户与抽取并发，不得双户同日有效镜）。
- 测试：`cd backend && PYTHONPATH=. python -m pytest tests/`（含并发与主链冒烟回归）。

## 重叠营业日窗票（已启用 · nn=24）

全局唯一口径：**以窗票强制坍缩为准**（不走「双史隔离」分支）。

- 并户成功必须在同一事务内同票开重叠窗票：按源/目标全部共同营业日落
  `重叠日窗票表`（票号、源键、目标键、重叠日集合、形态=强制坍缩）；
  无共同镜日则并户失败闭，**禁止并户成功而重叠窗票空**。
- 持票后重叠日只保留目标键正式镜：源键该日正式镜清空转归档，来源标
  「重叠坍缩归档」（隔离可读），**禁止双露**（双户同日两份有效镜）。
- 日终抽取/回放写前过窗票守卫：缺有效票或检出双露一律失败闭（HTTP 400）；
  已并户源键再抽正式镜拒绝（报告 `窗票拦抽`），仅留隔离归档。
- 回放按目标键：流水并户时已改挂目标（留 `原账户键`），源隔离镜不参与净额，
  **回放不加倍**；抽取/回放批次报告留 `关联窗票` 同票痕。
- 核证只读接口（基线所无）：
  - `GET /api/核证/重叠日窗` → 现场聚合（票清单、双露、valid、口径标志）；
  - `GET /api/核证/重叠日窗/票/{票号}` → 票号、重叠日、源正式有无、回放是否加倍、valid 及逐日明细。
- 两口径可区分点（本口径取值）：源键读正式有效镜=**无**；目标余额**不含**源隔离镜逐日复算；
  回放净额加倍=**否**。
- 夹具：`并户重叠窗票样例.json`（顺序，甲源正式空/目标续/不加倍、乙隔离可读再抽拒）、
  `重叠窗票并发样例.json`（并户与抽取抢锁，不得双正式加倍）。
- 删票现场：测试用 `重叠日窗票.删票测试用` 物理删票后，抽取与回放必须失败闭。
