# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
# 并户继承 → 并户继承夹具 / 并户并发夹具 → 凭证与继承只读视图
```

本地拆跑：

```bash
# API
cd backend && pip install -r requirements.txt
$env:夹具目录='..\fixtures'; uvicorn app.main:app --port 11600

# 前端
cd frontend && npm install && npm run dev
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜 |
| 回放核对 | 前日快照+当日流水 vs 当日快照 |
| 差额清单 | 不一致行 |
| 断档/跳变 | 缺前日镜、偏离阈值 |
| 旁置簿 | 未入账载荷 |
| 并户凭证 | 源→目标、生效日、源结转、源键暴露 |

## 并户继承镜（已启用）

口径：**源键只读归档**。

- 并户写路径在同一事务内：源户有效快照转「归档」只读 → 流水改挂目标（留 `原账户键`）→ 账户状态
  与去向/凭证 → 清理失效差额 → 落并户凭证 → 重算目标生效日及以后快照。任一步失败整笔回滚。
- 目标户接续源户已公布镜链条：生效日开端 = 目标前日 + 源户结转，且只加一次（目标已有后续有效镜即不再加）。
- 源户生效日后禁抽；并户后按源键装载的流水改挂承接目标。
- `GET /api/快照?账户键=户甲` → 空；`&含归档=true` → 归档只读行。
- 并户继承只读接口：`GET /api/并户/{凭证}` → 源、目标、生效日、`源键暴露`、`valid`、目标继承链、源归档链。
- 夹具：`并户继承样例.json`（顺序）、`并户并发样例.json`（并户与抽取并发，不得双户同日有效镜）。
- 测试：`cd backend && PYTHONPATH=. python -m pytest tests/`（9 项，含并发与主链冒烟回归）。
